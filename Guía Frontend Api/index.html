POKÉPORTAL API REST

Guía Frontend Consumo de API Pública (PokéAPI v2)

🔍 Búsqueda Individual de Pokémon

GET /api/v2/pokemon/:identificador

Ingresa el nombre (ej. Arceus, Pikachu, Gengar) o el número de Pokédex (ej. 1, 25, 493) para consultar sus datos en tiempo real.

Endpoint consumido: https://pokeapi.co/api/v2/pokemon/arceus

📋 Explorador de Pokémon por Rango

GET /api/v2/pokemon?limit={X}&offset={Y}

Establece el rango numérico de la Pokédex que deseas listar. El sistema traduce automáticamente el rango a los parámetros limit y offset de la API.

limit: 10 | offset: 0
Rangos rápidos:
Endpoint consumido: https://pokeapi.co/api/v2/pokemon?limit=10&offset=0
